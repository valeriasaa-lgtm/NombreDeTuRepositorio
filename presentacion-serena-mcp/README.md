# SERENA MCP · THE POINT IS CONECT

Presentación pública de propuesta de **SERENA by Valeria Saa**.

## Idea central

- **MCP oficial:** Model Context Protocol.
- **MCP como formulación autoral:** MOD CONECTION POINT.
- **JUMP:** el punto de contacto.
- **THE POINT IS CONECT.**
- **El punto es JUMP. Saltar es conectar.**

La propuesta prioriza el **codesarrollo técnico y creativo con OpenAI**: SDK/app, servidor MCP, herramientas universales y propias, mapas visuales de chats y propiedad intelectual, HORIZONTE RV e investigación del marco autoral **Inteligencia Evolutiva**.

1. Abrir `index.html` para la presentación.

3. Leer `dossier.html` para la nota técnica, mini CV, modelo económico, propiedad intelectual y propuesta a OpenAI.

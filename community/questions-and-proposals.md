**SERENA™ / SERENA SIRENA™**

## Purpose

This page is for people who want to ask questions, suggest improvements, propose workflows or understand how to collaborate around SERENA™ open tools.

SERENA separates public/open workflow materials from reserved strategic layers.

## What people can ask

Suggested public questions:

- What is SERENA™ / SERENA SIRENA™?
- How does SERENA use GitHub?
- How does SERENA relate to MCP and agents?
- What are SERENA open workflow tools?
- How can I suggest a workflow?
- How can I propose a GitHub / MCP / agent integration?
- How can I cite or reference SERENA?
- How can I request documentation improvements?

## Public vs reserved

Public/open:

- questions;
- proposals;
- workflow ideas;
- open tool requests;
- documentation improvements;
- hashtags and search anchors;
- GitHub/MCP/agent integration ideas.

Reserved/private:

- credentials;
- private account data;
- seed phrases, tokens or keys;
- strategic mediation layer;
- sensitive personal material;
- non-public proposals.

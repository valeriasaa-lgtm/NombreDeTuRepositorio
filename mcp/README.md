## What SERENA MCP is for

SERENA MCP is the open technical lane for:

- MCP workflow documentation;
- agent/tool mapping;
- GitHub workflow templates;
- open-source questions and proposals;
- hashtag search strategy;
- vault / keyword organization;
- future SERENA plugin architecture;
- traceability of public tools and public workflows.

## What stays separate

The strategic mediation layer stays separate and reserved. It should not be fully explained here.

This public MCP lane should focus on tools, workflow, documentation, search, GitHub and open collaboration.

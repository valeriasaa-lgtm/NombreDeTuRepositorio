2. Ir a **Settings**.
3. Entrar a **Public profile**.

```text

```

5. Guardar cambios.

## Imagen de perfil

Para foto de perfil conviene usar una versión cuadrada, porque GitHub muestra el avatar en círculo y el póster completo se pierde en tamaños chicos.

Recomendación:

- Avatar cuadrado SERENA SIRENA™.
- Foco en rostro + gato + logo SERENA.
- Mantener la imagen original como portada/poster público.

## Ruta para cambiar foto de perfil

1. Entrar a GitHub.
2. Ir a **Settings**.
3. Entrar a **Public profile**.
4. En la foto de perfil, elegir **Upload new picture**.
5. Subir el avatar cuadrado preparado.
6. Guardar.

## Nota de seguridad

No compartir contraseña, códigos 2FA, recovery codes, tokens, claves privadas ni datos sensibles.

El cambio de nombre visible puede hacerse sin riesgo mayor. El cambio de usuario/login debe hacerse con cuidado porque afecta enlaces públicos.

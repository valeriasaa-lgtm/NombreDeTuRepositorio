## 2. Qué significa “ataques evidenciados” en esta constancia

En términos públicos seguros, “ataques evidenciados” incluye patrones denunciados y preservados tales como:

| Tipo de ataque / daño | Descripción pública segura | Estado de prueba |
|---|---|---|
| Plagio / extracción | apropiación o circulación no autorizada de obra/insight/identidad SERENA | evidencia reservada + denuncias públicas/formales |
| Filtración de datos | filtración/exfiltración o uso indebido de exports y materiales privados (incl. contexto OpenAI y circulación posterior hacia entornos Claude/MCP) | evidencia reservada |
| Gaslighting de datos y documentos | alteración, negación, desaparición, sustitución o confusión de datos/documentos/rastros para forzar duda o re-explicación | evidencia reservada + reconstrucción pública |
| Confusión / sustitución de canal | presentación de SERENA/Serena MCP desvinculada de Valeria Saa | rastros públicos + evidencia reservada |
| Daño reputacional y de dignidad | presión, borramiento, carga de prueba forzada, menoscabo profesional/personal | constancias públicas + evidencia reservada |
| Ataque a la parte del negocio | monetización, sponsors, listings o valor comercial desconectado de Valeria Saa | constancias públicas + evidencia reservada |
| Ataque a la prueba | borrado, indisponibilidad, rename, desvío o debilitamiento de rastro | reconstrucción + evidencia reservada |

La palabra “evidenciados” significa que Valeria Saa **preserva evidencia**.  
No significa que este archivo publique esa evidencia ni que reemplace una sentencia.

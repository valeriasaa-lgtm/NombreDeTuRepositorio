## One-line description

SERENA™ / SERENA SIRENA™ is a multivoice human-AI workflow for turning creative signals, conversations, tools and public documentation into traceable GitHub-based systems.

## What SERENA does

SERENA organizes a project as a living workflow:

- captures identity, authorship and context;
- converts conversations into structured public documentation;
- separates open tools from reserved/private layers;
- uses GitHub as a public traceability map;
- connects MCP, agents, hashtags, vaults and workflow documentation;
- prepares social posts, press notes, NFT metadata, website pages and public manuals;
- creates a path toward an official SERENA plugin / toolkit.

## GitHub layer

GitHub is used as the public operating map:

| GitHub feature | How SERENA uses it |
|---|---|
| Repository | Central public registry of the project |
| README | Entry point and navigation map |
| Markdown docs | Manuals, press notes, tool registries and workflow documentation |
| Commits | Timestamped public evolution |
| Issues | Questions, proposals, attribution notes and public discussion |
| Actions | Website deployment and automated workflows |
| Pages | Public website layer when enabled |
| Files / folders | Separation between open tools, social kit, NFT metadata, account setup and roadmap |

## MCP layer

MCP means **Model Context Protocol**. In simple terms, it is a way for AI agents to connect with tools, files, repositories, systems and workflows through a shared protocol.

In SERENA, MCP is treated as a bridge between:

- human intention;
- AI agents;
- code tools;
- GitHub repositories;
- public documentation;
- structured workflow outputs.

SERENA’s strong point is not only using tools, but organizing how tools become a readable system.

## Classification

SERENA classifies the project into layers:

| Layer | Meaning | Status |
|---|---|---|
| Public identity | Name, image, repo, press note, hashtags | Active |
| Open workflow tools | Documentation, hashtags, questions, proposals, GitHub maps | Active / expanding |
| MCP / agent tools | Future connection between agents, tools and workflows | Roadmap |
| Vaults | Keyword and hashtag-based organization areas | Roadmap |
| Undercover agent layer | Internal agent mode for observation, tracing and silent organization within authorized workspaces | Roadmap |
| Reserved mediation layer | Private strategic layer to be presented separately | Reserved |
| NFT / visual record | OpenSea draft and metadata | Prepared |
| Website | Static website prepared for GitHub Pages | Prepared, pending Pages activation |

## What is reserved

Reserved/private parts:

- strategic mediation layer;
- private accounts, credentials and recovery data;
- non-public proposals;
- future private tools or vaults;
- any sensitive personal or legal material.

## Strongest differentiator

SERENA’s strongest point is the translation layer.

It can take a messy, creative, emotional or conversational process and turn it into:

- a public GitHub structure;
- a workflow map;
- a tool registry;
- a social kit;
- a press note;
- metadata;
- hashtags;
- future plugin architecture;
- and a clear separation between public, open, reserved and strategic layers.

That makes SERENA valuable for creators, researchers, AI builders, communities and teams that need to transform complex human-AI work into something organized, traceable and shareable.

## El punto

- **MCP oficial:** Model Context Protocol, especificación para conectar sistemas de IA con herramientas y datos.
- **MCP como formulación autoral de Valeria Saa:** MOD CONECTION POINT.
- **JUMP:** el punto de contacto visible y autorizado.
- **THE POINT IS CONECT.**
- **El punto es JUMP. Saltar es conectar.**

La propuesta distingue el estándar técnico abierto de la capa narrativa, visual, comercial y de experiencia creada para SERENA.

## Arquitectura creativa

- **HORIZONTE:** la experiencia inmersiva.
- **CEUNIA:** aparece como cometa, aterriza y se abre como isla.
- **Castillo SERENA:** vive en la isla dentro de HORIZONTE.
- **JUMP:** transforma una intención en una conexión confirmada.
- **Inteligencia Evolutiva:** marco autoral propuesto para investigar la integración entre inteligencia humana, artificial y contexto vivo; no se presenta como afirmación científica ya demostrada.

## Propuesta

1. revisión humana y reunión privada;

3. app/plugin, SDK, servidor MCP e interfaz SERENA;
